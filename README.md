# MedChain – A Blockchain-Based Secure Medical Records Management System

MedChain is a decentralized healthcare application designed to securely manage, store, and share medical records using blockchain technology. The project aims to address major issues in traditional healthcare systems such as data tampering, unauthorized access, lack of transparency, and centralized control of sensitive patient information.

The system uses Ethereum smart contracts to ensure immutability and trust while implementing role-based access control for different stakeholders such as administrators, doctors, and patients. Patients maintain ownership of their medical data and have full control over granting or revoking access permissions.

To improve scalability and efficiency, medical records are stored off-chain using the InterPlanetary File System (IPFS), while cryptographic hashes of the records are stored on the blockchain to guarantee data integrity. A web-based user interface allows seamless interaction with the blockchain through wallet-based authentication.

## Key Features
- Secure and tamper-proof medical record management
- Patient-controlled access permissions
- Role-based access control (Admin, Doctor, Patient)
- Smart contract–based data validation
- IPFS integration for decentralized file storage
- Ethereum blockchain for transparency and immutability
- Web-based interface with wallet connectivity

## Technologies Used
- Solidity – Smart contract development  
- Ethereum & Hardhat – Blockchain framework  
- IPFS – Decentralized file storage  
- React with Vite – Frontend development  
- Ethers.js – Blockchain interaction  

## Objective
The primary objective of MedChain is to demonstrate how blockchain technology can be effectively applied in healthcare systems to enhance data security, privacy, and trust while empowering patients with ownership of their medical information.

## Academic Note
This project is developed strictly for educational and research purposes and demonstrates the practical application of blockchain concepts in a real-world healthcare use case.
